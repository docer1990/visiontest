# Release 0.2.0 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use agentico:subagent-driven-development or agentico:executing-plans to implement this plan task-by-task.

**Goal:** Prepare the 0.2.0 branch with reliable wait validation, useful agent instructions, and release migration guidance.

**Architecture:** Keep CLI adapters delegating to shared registrars. Keep the skill embedded in the JAR and obtain its provenance from `VersionInfo`; preserve the existing frontmatter fields and offline generation.

**Tech Stack:** Kotlin, Clikt, JUnit, MockWebServer, Gradle, Markdown.

## Task 1: Validate waits before device access

**Files:**
- Modify `app/src/main/kotlin/com/example/visiontest/cli/commands/WaitForElementCommand.kt`.
- Modify `app/src/main/kotlin/com/example/visiontest/tools/AndroidWaitToolRegistrar.kt` and `IOSWaitToolRegistrar.kt`.
- Add `app/src/test/kotlin/com/example/visiontest/cli/WaitValidationCliTest.kt`.
- Modify the corresponding registrar tests and `docs/agentico/specs/element-waits.md` and `cli.md`.

**Review:** checkpoint, public validation contract.

- [ ] Add failing tests for both platforms and both wait modes. Missing selectors, timeouts outside 1..30000, Android app scope, and blank iOS scope must exit 2 without resolving lazy components. A nonblank iOS bundle alone is insufficient. Mirror the injectable `CliCommandRunner` pattern in `FindElementCommand` to test actual command parsing. The key assertion is `assertFalse(components.isInitialized())` after `assertEquals(2, result.exitCode)`.
- [ ] Add registrar tests that pass invalid selectors or timeout to an unavailable backend and expect `IllegalArgumentException` with `assertEquals(0, server.requestCount)`. Preserve valid wait behavior and protocol failure coverage.
- [ ] Implement validation before component construction and health checks. Preserve selector mappings, polling intervals, timeouts, and returned result formats. Update contracts to remove the old health-before-validation requirement.
- [ ] Run `./gradlew :app:test --tests '*Wait*' :app:detekt`, resolve new findings, and commit the correction.

# VisionTest 0.2.0

VisionTest 0.2.0 expands the CLI and MCP workflow for reliable end-to-end mobile
testing. The generated project skill now explains CLI and MCP use, checks
operation results, guides screenshot review, describes platform limitations, and
identifies its source VisionTest version.

## Highlights

- Added structured JSON output for UI inspection, device information, app lists,
  and app details.
- Added element waits and selector-based taps, swipes, long presses, double taps,
  and targeted text entry for Android and iOS.
- Added iOS app scoping, alert handling, keyboard dismissal, and a prebuilt
  XCUITest bundle on supported macOS arm64 hosts.
- Improved the Android CLI with explicit platform selection, JSON validation,
  and consistent command results.
- Fixed wait commands so invalid arguments fail before backend access.
- Added `visiontest init` to install or refresh project-local instructions for
  Claude, OpenCode, and Codex.

## Upgrade

Re-run the installer to upgrade the JAR, Android APKs, and, on supported Macs,
the iOS bundle. Restart the automation server after updating native artifacts.
An older native server can report a method-not-found error even when the JAR is
current.

In each project using VisionTest, run `visiontest init --agent <agents>` again
to refresh its generated skill. Init replaces the selected skill files
completely; save any project-specific edits first.

Device commands continue to require `--platform android|ios`. Android field
clearing is supported; generic iOS text clearing and explicit CLI selection among
multiple attached devices are not available in this release. The prebuilt iOS
bundle requires macOS arm64 and a compatible Xcode version. Other supported
hosts can build from source.

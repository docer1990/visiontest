# CLI flow implementation plan

> Use agentico:subagent-driven-development and review each checkpoint.

**Goal:** Implement issue #56 with validated sequential actions and observations.
**Architecture:** Prepare commands before components exist. Execute shared registrar
operations once per step with structured outcomes and scoped HTTP deadlines.
**Tech Stack:** Kotlin, Clikt, kotlinx.coroutines, JUnit 5, MockWebServer.
**Branch:** feat/issue-56-flow off main (58d188a).
**Decisions:** TD-003, TD-006, TD-016.

## File structure
- `tools/ScreenshotSaver.kt` owns typed screenshot persistence results.
- `common/JsonRpcHttpClient.kt` owns scoped transport deadlines and dispatch evidence.
- `cli/FlowInput.kt` tokenizes flow sources without a shell.
- `cli/FlowPreparation.kt` prepares operations using existing command definitions.
- `cli/FlowExecutor.kt` executes and classifies results.
- `cli/FlowObservationCollector.kt` collects bounded observations and evidence.
- `cli/FlowReport.kt` owns report values and serialization.
- `cli/commands/FlowCommand.kt` parses flow options and renders CLI results.
- Existing command adapters expose a preparation seam without duplicated arguments.
- `app/src/test/resources/features/flow.feature` defines acceptance scenarios.

## Task 1: Shared structured results and deadline scope
**Review:** checkpoint.
Add a typed screenshot result with success, message and optional absolute path;
preserve capture/write text wrappers. Add a scoped request budget with dispatch
evidence in the shared HTTP transport; standalone calls retain existing semantics.

within the flow budget, recording possible dispatch. Use TDD and run the affected
screenshot/client tests with `./gradlew :app:test --tests '*Screenshot*' --tests '*Deadline*' --quiet`.

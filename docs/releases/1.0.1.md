# VisionTest 1.0.1

VisionTest 1.0.1 updates the agent skill embedded in the CLI with explicit rules
for exploration, recorded tests, app lifecycle and evidence collection. CLI
commands, MCP tools and native automation protocols retain their 1.0.0 behavior.

## Agent guidance changes

- Batch known exploratory actions with `flow --json` without recording. Record
  complete, defined scenarios that still need testing with `flow --record --json`.
- Terminate and relaunch the app before every recorded test, checking each result.
  Include navigation from the fresh launch in the recorded scenario and wait for
  recording finalization before closing the app again.
- Use built-in actionability and element waits instead of sleeps, including
  `sleep 0`. Reuse known selectors for requested reruns and verify each command's
  supported options; `swipe_direction` does not accept `--bundle-id`.
- Use structured CLI results for functional assertions. Reserve screenshots for
  observed UI bugs or assertions that structured queries cannot establish, with
  the same restrictions on automatic failure screenshots.
- Review saved flows after the final edit, preserve requested assertions and
  choose explicit assertion timeouts. Distinguish missing prerequisites from
  failed assertions and retain complete results and errors.

These are agent instructions, not new runtime enforcement in the CLI. The
recording flag remains opt-in, and following the guidance does not guarantee that
every model will choose the correct commands.

## Upgrade

Follow the [installation guide](../installation.md) to update VisionTest. The JAR
and Android version name are `1.0.1`; Android's version code is `4`.

After upgrading, run these commands in each application repository, choosing the
agents used by that project:

```bash
visiontest --version
visiontest init --agent claude,opencode,codex
```

Confirm that the installed CLI reports `1.0.1`. Updating the binary does not
replace existing project-local skills; `init` writes the instructions embedded
in that binary and overwrites the selected skill files, including local edits.
Start a new agent session so it loads the updated instructions.

See [the CLI flow guide](../cli-flow.md) for recording and lifecycle details,
and [the guidance trials](../benchmarks/cli-agent-guidance.md) for simulated checks
and their limits.
